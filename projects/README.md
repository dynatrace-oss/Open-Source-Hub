# Dynatrace Open Source Projects

This directory provides an overview of the public open source projects maintained, supported, sponsored, or facilitated by Dynatrace.

The project portfolio is intended to make repository status and support expectations easier to understand.

## Project classifications

Repositories may be classified as:

### Strategic

Projects receiving deliberate investment because they directly support a Dynatrace product, important technical ecosystem, platform capability, or strategic initiative.

### Active community-supported

Projects that remain actively maintained and useful but are not covered by standard Dynatrace product support.

### Experimental

Research, prototypes, demonstrations, incubating projects, or other time-bound initiatives.

### Maintenance-only

Projects that remain useful but are no longer receiving significant feature development.

### Archived

Projects retained for reference after active maintenance has ended.

## Support classification is separate

Portfolio classification and support classification are not the same thing.

For example:

- A strategically important project may still be community-supported.
- A mature officially supported SDK may be maintenance-only.
- An active upstream fork may still be a candidate for transfer.

Always consult the individual repository README for support expectations.

## Portfolio data

Where practical, project information should be generated from structured repository metadata rather than maintained manually in multiple locations.

Future repository metadata may include:

- Repository.
- Owning team.
- Maintainers.
- Support model.
- Lifecycle status.
- Strategic classification.
- Ecosystem.
- Last review date.
- OpenSSF Scorecard.
